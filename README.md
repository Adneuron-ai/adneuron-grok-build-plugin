
# AdNeuron for Grok Build

AI-powered advertising copilot to create, manage, analyze, and optimize campaigns across multiple ad platforms.

## Supported Platforms

- Google Ads
- Meta Ads

Additional advertising platforms may be supported in future releases.

## Features

- Discover connected advertising accounts
- Analyze campaign performance
- Review budgets, spend, clicks, and impressions
- Generate campaign optimization recommendations
- Create and manage advertising campaigns

## MCP Server

AdNeuron uses a remote MCP server:

https://mcp.adneuron.ai/mcp

## Setup

1. Create an account at https://adneuron.ai
2. Connect your Google Ads or Meta Ads account.
3. Install the AdNeuron plugin in a compatible Grok Build environment.
4. Authenticate with AdNeuron when prompted.
5. Ask the assistant to retrieve advertising data.

## Example Prompts

- List my connected advertising accounts.
- Show my active Meta Ads campaigns.
- Analyze my Google Ads performance for the last 30 days.
- Recommend improvements to my campaigns.

## Security

AdNeuron requires authorized access to advertising accounts.
Review proposed campaign changes before approving actions that
affect advertising spend.
